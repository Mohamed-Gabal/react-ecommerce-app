# E-Commerce Forever

A modern React e-commerce web application built with Context API, focusing on clean UI, performance, and responsive design.

---

## Features
- Product listing with filtering
- Add / Remove from cart
- Cart total calculation
- Context API state management
- Lazy loading (performance optimization)
- Fully responsive design (mobile, tablet, desktop)

---

## Tech Stack
- React
- JavaScript
- Context API
- Tailwind CSS
- Vite

---

## How to run

```bash
npm install
npm run dev
